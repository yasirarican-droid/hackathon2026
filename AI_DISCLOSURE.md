# AI use and human contribution

Abandoned, But Not Forgotten is a team-led educational project for school-age explorers. The team selected the concept, three-mission scope, sources, story direction, visual style and interaction priorities. Project roles and responsibility statements are documented in the README and SPACE_APPS_PAGE.md.

| Tool | Purpose | Disclosure / Labeling |
|---|---|---|
| **OpenAI Codex** | Software implementation, integration assistance, explanatory text and automated checks | Project Info, source documentation and AI usage records |
| **OpenAI ImageGen / ChatGPT** | Illustrated control rooms, interface artwork, fictional guides and visual production assistance | Shared project Info and per-asset provenance records |
| **ChatGPT + Kling AI** | Team-supplied illustrated arrival films | AI production credits in the films and project Info |
| **ElevenLabs** | Mission introductions, archive stories, naming story and Last Signal narration | Project Info, descriptive provenance and MP3 metadata; separate from historical audio |
| **Suno** | Homepage music | Project Info and audio provenance/metadata |

The shared project Info card identifies tools and the roles of generated illustrations, creative films, synthetic narration and music. Arrival films carry AI production credits; the owner confirms the Apollo mark is included within its video. Synthetic audio is identified in descriptive records and MP3 metadata. The owner confirms paid-plan production for ElevenLabs and Suno.

NASA evidence remains separate: original photographs, the PDS pressure samples, historical Apollo audio, NASA/JPL podcast voices and NASA-issued model geometry are credited to their sources. Educational Sojourner/Pathfinder geometry is project-authored and documented as a simplified reconstruction.

Last Signal is a modern sourced narrator story, not an authentic final transmission. Decorative control rooms and characters are fictional. Source rows, image IDs, original hashes and uncertainty statements are retained. No synthetic scientific measurements are presented.

Per-file records: public/content/ai-usage.json, production-audit.json, narration.json, media.json, archival-audio.json, sojourner-recordings.json, model.json, viking-model.json and sojourner-models.json. Provider terms remain separate from the Apache-2.0 code license; see THIRD_PARTY.md.

This document records attribution and production roles. It does not assert an award, official endorsement or independent compliance certification.
